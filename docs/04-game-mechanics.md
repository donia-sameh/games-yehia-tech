# قواعد اللعب
↩ [الرئيسية](../README.md) · [الفيجن والخطة](00-vision-and-plan.md)

**الحالة:** متوافق عليه (اللي مكتوب جنبه D-0xx مقترح)

## الشاشة
```
[ لوجو ]                 [ ديمو ] [ ابدأ من الأول ] [ النقط ]
[ ليفل 1 ][ ليفل 2 ][ ليفل 3 ] ...  ← شريط الليفلز
┌──────────── السؤال ─────────────┐   ┌ فقاعة ┐
│ [ الكود ]        [ المعاينة ]     │   │ يحيى  │
│ [ تحقّق ] [ تلميح ] [ اللي بعده ] │   └───────┘
└──────────────────────────────────┘
```

## الليفل
- كل ليفل ليه **بنك 10 أسئلة**، واللاعب بيتعرض عليه **سؤالين** (D-017).
  - البنك: 5 «اكتب» + 5 «اختار». بيتسحب واحد من كل نوع (D-018).
  - كل ملف ليفل فيه جدول «ممنوع يتجمعوا».
  - «العب تاني» بيسحب سؤالين جداد.
- الصعوبة بتزيد من ليفل للي بعده (D-019).
- اللاعب بيشوف **سؤالين** (D-011).
  - السؤال 1 بيعلّم الفكرة.
  - السؤال 2 بيجيب أشهر غلطة فيها.
- الليفلز بتتفتح بالترتيب.
- لما الليفل يخلص: نجوم، وملخص، وفتح الليفل اللي بعده، ويحيى يدّي teaser عنه.

## الميكانيكس (D-012)
| # | الاسم | إزاي |
|---|---|---|
| ① | **اكتب** | فراغ في الكود، والمعاينة بتتحدّث مع كل حرف. «تحقّق» أو Enter |
| ② | **اختار** | 3-4 اقتراحات. الـ hover بيجرّب لو التجربة مش بتكشف الإجابة، والضغطة بتثبّت |
| ③ | **رتّب** | سحب سطور الكود. في الليفل الأخير بس |

## المعاينة
- الكود بيتطبّق على عناصر حقيقية، والمتصفح هو اللي بيقرّر النتيجة.
- في HTML World: المعاينة `iframe` حقيقي، وفوقها تابة بتعرض الـ `title`، وتحتها «نضارة قارئ الشاشة» (D-020).
- عليها ختم بيقول الحالة (قبل / بعد / مستخبي / ظهر!).
- لما الإجابة صح: حركة pop على العنصر اللي اتصلّح.

## النقط
| الحدث | النقط |
|---|---|
| إجابة صح | +100 |
| صح من أول محاولة | +50 زيادة |
| تلميح (مرة واحدة في السؤال) | −20 |
| إجابة غلط | 0 |

- بعد غلطتين: يحيى يقترح التلميح.
- النقط بتتجمّع على مدار الليفلز.

## النجوم
- ⭐⭐⭐: من غير ولا غلطة ولا تلميح.
- ⭐⭐: الغلطات والتلميحات مع بعض 3 أو أقل.
- ⭐: غير كده.

## وضع الديمو
- زرار «شغّل الديمو» بيلعب الليفل اللي على الشاشة لوحده: ماوس متحرك، وغلطة أو اتنين، وتلميح، وبعدين الحل.
- «ابدأ من الأول» بيوقفه.
- كل ليفل ليه سكريبت ديمو.

## اللينكات
- `#level2` و`#level3`… بيفتحوا الليفل ده على طول.
