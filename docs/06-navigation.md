# الشاشات والتنقّل

**الحالة:** متوافق عليه (اللي جنبه «مقترح» مستني تأكيد) · **آخر تحديث:** 2026-10-13
↩ [الرئيسية](../README.md) · [الفيجن والخطة](00-vision-and-plan.md)

## الفلو
```
اللاندنج (كل الألعاب)
   └─ HTML World ← خريطة الليفلز (طريق بنقط)
         └─ ليفل N ← شاشة «ابدأ»
               └─ سؤالين ← «خلّصت الليفل»
                     ├─ ليفل N+1 ← شاشة «ابدأ» بتاعته
                     └─ ارجع للخريطة
```

## 1. اللاندنج: `games.yehia.tech` (D-021)
- **فوق:** «اتعلم البرمجة وإنت بتلعب»، ويحيى، وزرار «ابدأ بـ HTML World».
- **كروت الألعاب:**

  | اللعبة | الحالة على الكارت | الدوسة |
  |---|---|---|
  | HTML World | متاحة، و12 ليفل، وشريط تقدّم | بتفتح الخريطة |
  | CSS World | قريبًا | مقفولة |
  | ألعاب تانية | قريبًا | مقفولة |

- **«إزاي بتلعب»:** 3 خطوات: اقرا المشكلة، وصلّح الكود، وشوف النتيجة.

## 2. خريطة الليفلز: Road Map (D-022)
- **الشكل:** طريق متعرّج من فوق لتحت، وبين كل ليفل واللي بعده نقط زي ألعاب الموبايل.
- **المراحل:** لافتة في أول كل مرحلة (النص، وروابط وصور، والفورم، والاختيارات والبيانات والبوس).
- **حالات الليفل:**

  | الحالة | الشكل |
  |---|---|
  | مقفول | رمادي متقطّع، وعليه قفل |
  | مفتوح (الحالي) | أصفر، وبينبض، ويحيى واقف فوقه وجنبه «إنت هنا» |
  | خلص | أبيض، وتحته النجوم اللي خدتها |

- **النقط:** الجزء اللي خلص من الطريق أسود، والباقي رمادي.
- الليفل بيتفتح لما اللي قبله يخلص.
- **فوق الخريطة:** «← كل الألعاب»، ومجموع النقط، والتقدّم (مثلاً 2 من 12).

## 3. شاشة «ابدأ» (D-023)
- رقم الليفل واسمه، والتاجات اللي بيعلّمها.
- **هتتعلم:** 2-3 نقط من قسم «اللاعب بيطلع بإيه» في ملف الليفل.
- «سؤالين من بنك 10 · لحد 300 نقطة».
- يحيى بيقول جملة تشجيع.
- زرار **«ابدأ اللعب ▶»**، وزرار «ارجع للخريطة».
- لو الليفل لسه ملوش أسئلة: الشاشة بتقول «الليفل ده لسه بيتكتب»، وزرار البداية مقفول.

## 4. اللعب
نفس [قواعد اللعب](04-game-mechanics.md)، وفوق زرار «← الخريطة».

## 5. «خلّصت الليفل» (D-024)
- النجوم، والنقط، والغلطات، والتلميحات.
- زرار أساسي: **«ليفل N+1: اسمه ←»**، وبيودّي على شاشة «ابدأ» بتاعته.
- زرار تاني: «ارجع للخريطة»، والخريطة بتتحرك ويحيى ينقل على الليفل الجديد.
- زرار «العب تاني بأسئلة جديدة».

## التقدّم
- **في البروتوتايب:** بيتحفظ في المتصفح (`localStorage`): أحسن نجوم ونقط لكل ليفل. **مقترح** (D-025)، والقرار النهائي في [Q-04](05-open-questions.md).
- **مجموع النقط** = مجموع أحسن نقط في كل ليفل.
