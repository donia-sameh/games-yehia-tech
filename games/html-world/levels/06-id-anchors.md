# ليفل 6: الـ id والقفز
[← ليفل 5](05-images.md) · [كل الليفلز](../README.md) · [ليفل 7 →](07-input-types.md)

| | |
|---|---|
| **المرحلة** | روابط وصور |
| **بيعلّم** | `id` · `#` |
| **الحالة** | مسودة |

## المشكلة
لينك «تواصل معانا» اللي فوق في الصفحة مبيروحش في حتة.

## سؤال 1 (اكتب)
```html
<a href="#contact">تواصل معانا</a>
...
<section __="contact">...</section>
```

**الإجابة:** `id`: الصفحة بتنزل لوحدها لحد السكشن، وبيلمع.

| الإجابة | اللي بيحصل في المعاينة | يحيى بيقول |
|---|---|---|
| `class` | مفيش قفز | «الـ # بتدوّر على attribute تاني.» |
| `name` | مفيش قفز | «name للفورم (هتشوفه في ليفل 10).» |
| `href` | مفيش قفز | «href مكانه في اللينك، مش في السكشن.» |

## سؤال 2 (اختار)
سكشن تاني `id="courses"`. قيمة `href` في اللينك تبقى إيه؟

**الإجابة:** `#courses`

| الإجابة | اللي بيحصل في المعاينة | يحيى بيقول |
|---|---|---|
| `courses` | بيدوّر على صفحة اسمها courses | «من غير # بيدوّر على صفحة، مش على حتة في الصفحة.» |
| `#Courses` | مفيش قفز | «الـ id بيفرّق بين الحروف الكبيرة والصغيرة.» |
| `# courses` | مفيش قفز | «مفيش مسافات.» |

## اللاعب بيطلع بإيه
- `id` اسم فريد لعنصر واحد.
- `href="#الاسم"` بيقفز للعنصر ده.
- الـ id بيفرّق بين الكبير والصغير، ومفيهوش مسافات.

## الربط بليفلز تانية
بدل ليفل الـ id اللي في البروتوتايب (D-014). الـ `id` بيرجع في [ليفل 8](08-labels.md).

## الديمو
يكتب `class` (غلط) ← تلميح ← `id` ← صح والصفحة تنزل ← في سؤال 2 يختار `courses` وبعدين `#Courses` وبعدين `#courses`.
