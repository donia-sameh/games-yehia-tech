# Yehia Tech Games

ألعاب تعليمية تفاعلية على `games.yehia.tech`.

## طريقة الشغل: Spec-Driven
1. أي فكرة أو تغيير يتكتب في الـ spec **الأول**.
2. أي قرار يتسجّل في [docs/01-decisions.md](docs/01-decisions.md) برقم.
3. البناء بيبدأ بس بعد ما الـ spec حالته **متوافق عليه**.
4. لو الكود خالف الـ spec، نصلّح واحد فيهم، ميفضلوش مختلفين.

## حالات الـ spec
- **مسودة**: لسه بنفكر.
- **متوافق عليه**: جاهز للبناء.
- **اتبنى**: موجود في الكود.
